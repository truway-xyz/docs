# FAQ

**Do I have to install anything?** No. The supervisor and the coordinator use a web page; the field team uses WhatsApp.

**Does this replace SECOP?** No. SECOP publishes the contract; Truway shows how it is being spent. Truway will read the contract from SECOP, never write into it.

**Who can see the invoices?** The file itself stays private with the organisation, which decides whether to share it. The public file shows each expense and a fingerprint of its invoice, which proves which file was approved without revealing it.

**What if someone makes a mistake?** A pending expense can be rejected, and the rejection is recorded too. An approved expense can never be deleted or edited; a way to record corrections is not built yet.

**Can the supervisor approve their own expense?** No. The person who files an expense can never approve it. The rule is part of the record itself.

**Can the same invoice be used twice?** Not within the same organisation. Across organisations, it is coming next.

**Does Truway handle the money?** No. Public money is paid by the agency and the organisation through their banks.

**What does it cost?** The 90-day pilot costs the agency nothing. Prices are not published yet.

**Is it live?** It runs on a test network with demo data. See [Current status](../about-truway/status.md).
