# Inicio

Truway convierte un contrato público en un expediente que cualquiera puede comprobar: cada factura, quién la propuso, quién la aprobó y cuánto queda del rubro, a la vista de cualquier veedor y sin poder borrarse en silencio.

## Empieza por donde estás

| Eres                                                                         | Empieza aquí                                                                                                                       |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Una **entidad pública** o el **supervisor** de un contrato                   | [Para la entidad y el supervisor](sector-publico/entidad-y-supervisor.md)                                                          |
| Una **organización que ejecuta dinero público** (ESAL, federación, operador) | [Para el ejecutor](sector-publico/ejecutor.md)                                                                                     |
| Una **veeduría**, un concejal, una contraloría o un ciudadano                | [Para el veedor y el ciudadano](sector-publico/veedor-y-ciudadano.md)                                                              |
| Un **revisor técnico** (financiador, panel, auditor)                         | [Modelo de confianza](arquitectura-y-stellar/modelo-de-confianza.md) y [Verifícalo tú mismo](arquitectura-y-stellar/verificalo.md) |
| Un **desarrollador** que quiere implementar o leer el estándar               | [Qué es Proof of Spend](proof-of-spend/proof-of-spend.md)                                                                          |

## Qué es real hoy

Todo corre en la red de pruebas (**testnet**) de Stellar con datos de demostración. Nada está en la red principal. Cada página dice si lo que describe está _En testnet_, _Construido, sin desplegar_, _En diseño_ o _En la hoja de ruta_. El panorama completo está en [Estado actual](conoce-truway/estado-actual.md).

## Las partes de esta documentación

* **Conoce Truway:** qué hace, para quién, cómo se sostiene y hacia dónde va.
* **Sector público:** cómo funciona un expediente, paso a paso, sin vocabulario técnico.
* **Proof of Spend:** el estándar abierto de ejecución presupuestal que Truway implementa.
* **Arquitectura y Stellar:** contratos, firmas, eventos, verificación y seguridad. Por ahora el detalle completo está en inglés; cada página trae un resumen en español.
