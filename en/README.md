# Truway Docs

Truway turns a public contract into a file anyone can check: every invoice, who proposed it, who
approved it and how much of the budget line is left, visible to any oversight body and impossible
to erase quietly.

## Start where you are

| You are | Start here |
|---|---|
| A **government agency** or a contract **supervisor** | [For agencies and supervisors](public-sector/agencies-and-supervisors.md) |
| An **organisation that executes public money** (non-profit, federation, operator) | [For executing organisations](public-sector/executing-organisations.md) |
| A **citizen oversight group**, a council member or an auditor | [For citizen oversight](public-sector/citizen-oversight.md) |
| A **technical reviewer** (funder, grant panel, security auditor) | [Trust model](architecture/trust-model.md), then [Verify it yourself](architecture/verify-it-yourself.md) |
| A **developer** who wants to implement or read the standard | [What is Proof of Spend](proof-of-spend/README.md) |

## What is real today

Everything runs on the Stellar **testnet** with demo data. Nothing is on mainnet. Each page says
whether what it describes is *Live on testnet*, *Built, not deployed*, *Design* or *Roadmap*. The
full picture is in [Current status](about/status.md).

## The parts of these docs

- **About Truway**: what it does, for whom, how it makes money and where it is going.
- **Public sector**: how a contract file works, step by step, with no technical vocabulary.
- **Proof of Spend**: the open standard for budget execution that Truway implements.
- **Architecture and Stellar**: contracts, signatures, events, verification and security, down to
  the parameter.
