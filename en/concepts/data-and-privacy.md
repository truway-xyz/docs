# Data and privacy

The public record keeps only amounts, codes and fingerprints. Personal data and files stay in Truway's private storage.

## Where each piece of data lives

| Data | Where | Who sees it | How long |
|---|---|---|---|
| Budget per line, account and source | Public record | Anyone | Permanent |
| Approved expenses: amount, line, account, date | Public record | Anyone | Permanent |
| Who proposed and who approved | Public record, as an anonymous code per person | Anyone; only the organization knows whose code it is | Permanent |
| Invoice fingerprint | Public record | Anyone | Permanent |
| Invoice or receipt file | Private storage | The organization and whoever it shares it with | Defined before the first pilot |
| Supplier name and tax ID | Truway's database; on the record only as a fingerprint | The organization | Defined before the first pilot |
| Names of people and phone numbers | Truway's database | The organization | Defined before the first pilot |
| WhatsApp messages | Truway's database | The organization | Defined before the first pilot |
| Beneficiary data | Truway does not receive it | | |

## Commitments

* Truway does not touch or hold public money. Payments are made by the agency and the organization through their banks.
* Truway does not write into government systems.
* Data can be exported at any time, as CSV and JSON.
* AI reads invoices but never approves: every expense is approved by a person.

## What the organization decides

Which names appear next to each expense in the public program file and which documents it shares. By default the supplier and the amount are shown, which are public information in a public contract.
