# Verify an expense

Anyone can verify an expense: oversight groups, council members, comptrollers or citizens. No account needed.

## Steps

1. Open [app.truway.xyz/proof](https://app.truway.xyz/proof).
2. In **Expense code**, type the code, for example `PAY-2026-0004`, and press **Verify**.
3. Review the expense: amount, budget line, **Account code**, **Funded by**, **Recorded by** and **Approved by**.
4. If you have the invoice, drop it on **Check the receipt** or press **Choose file**.
   * **Receipt matches**: it is exactly the file that was approved.
   * **This is not the approved receipt**: the file is different.
5. To see the same record outside Truway, press **View on Stellar**.

The file is checked in your browser and is never uploaded.

{% hint style="info" %}
Another photo of the same paper invoice will not match: the fingerprint belongs to the file. See [Public record](../concepts/public-record.md).
{% endhint %}
